**Spec:** `PLAN.md`, Unit F2.6; repair cases supplied in the task prompt.

## Global Constraints

- API routes remain under `/api/v1`; errors use `{"error": "..."}` and user-facing messages remain Indonesian.
- Data remains scoped by store from the token; cashiers remain scoped to their assigned active outlet.
- Cache Go builds on disk; do not use `/tmp` for Go cache or temporary files.
- Do not change frontend files or commit.

## Review Focus

- Omitted `isDefault` preserves a default outlet; explicit `false` cannot remove its default status.

- Admin list filters select the requested outlet; omitted transaction filter preserves aggregate admin behavior, and cashier requests remain pinned to their active outlet.
- Movement requests without `outletId` preserve the existing active-outlet behavior.
